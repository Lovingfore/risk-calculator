# 交易风险计算器设计

## 目标

建立公开 GitHub 仓库 `risk-calculator`，提供一个可通过 GitHub Pages 访问的中文单页计算器。用户输入账户本金、开仓价和止损价，页面计算投入保证金和杠杆倍数。首版不需要账号、后端或外部 API。

## 计算规则

- 将输入本金视为 USDT 账户资金，最大止损风险为其 1%。
- 杠杆目标固定为 80x，显示为整数杠杆。
- 按 Binance USDⓈ-M USDT 本位线性合约计算，使用普通账户吃单费率假设 0.05%/边；将开仓费和止损平仓费都计入风险预算。
- 止损价与开仓价的绝对距离用于风险计算，不要求额外输入多空方向。
- 止损必须按输入价格成交。滑点、资金费率、VIP/BNB 折扣、交易所最小名义价值和强平机制不纳入模型；页面会说明这些限制。

令本金为 `P`，开仓价为 `E`，止损价为 `S`，单边吃单费率为 `f = 0.0005`，目标风险额为 `R = 0.01 * P`。每单位数量在止损时的价格损失与双边手续费合计为：

```text
unitLoss = abs(E - S) + f * (E + S)
quantity = R / unitLoss
entryNotional = quantity * E
initialMargin = entryNotional / 80
```

如果计算出的保证金大于账户本金，则保证金限制为本金，并据此缩减数量和名义仓位。止损损失使用最终名义仓位和双边手续费重新计算，确保页面展示的理论值不高于本金的 1%。金额按 USDT 分精度向下取整，风险核对使用取整后的实际保证金。

## 页面行为

- 首屏直接呈现三项输入和计算结果，不提供营销介绍或额外导航。
- 输入变化时即时更新结果。
- 结果突出显示投入保证金与 80x 杠杆，并展示仓位名义价值、预计止损损失和风险占比，便于核对 1% 上限。
- 非正数、非有限数字、开仓价与止损价相同，以及不能形成至少 0.01 USDT 保证金的情况显示可读错误，不显示旧结果。
- 页面明确显示吃单费率假设以及未计滑点、资金费率和强平机制的说明。
- 使用纯静态 HTML、CSS 和 JavaScript，不收集或保存输入。

## 部署与验证

- 公开仓库使用 GitHub Actions 将主分支静态文件部署到 GitHub Pages。
- 计算函数使用无第三方依赖的 JavaScript 模块，并用 Node.js 内置测试覆盖手续费、风险上限、保证金上限和无效输入。
- 推送后检查 Actions 部署结果，并在桌面与窄屏视口检查页面布局和输入反馈。
